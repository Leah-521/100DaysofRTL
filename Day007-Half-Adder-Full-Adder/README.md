# 半加器与全加器设计说明

## 1. 半加器（Half Adder）

半加器是一种实现两个一位二进制数相加的组合逻辑电路，具有两个输入端（A、B）和两个输出端（Sum、Cout）。

其主要功能是计算两个二进制数的和，并输出相应的进位。半加器不考虑低位传入的进位，因此只能用于两个二进制位的加法运算。

## 2. 全加器（Full Adder）

全加器是一种能够实现三个一位二进制数相加的组合逻辑电路，具有三个输入端（A、B、Cin）和两个输出端（Sum、Cout）。

与半加器相比，全加器增加了进位输入端，能够同时处理两个本位输入和低位传递的进位，适用于多位二进制加法运算。

## 3. 两者区别

半加器只能计算两个一位二进制数之和，而全加器能够计算两个一位二进制数及一个进位输入之和。全加器功能更加完整，是构成多位加法器的重要基础。

## 4. 设计总结

通过半加器与全加器的设计，可以理解二进制加法的基本原理，掌握组合逻辑电路的设计思想，为后续学习多位加法器、算术逻辑单元（ALU）及数字 IC 前端设计打下基础。
